ชุดโครงการชุมชนที่สร้างขึ้นบน KREONYX CLI

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ KREONYX CLI ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-kreonyx](https://github.com/awesome-kreonyx/awesome-kreonyx) และ [kreonyx.cafe](https://kreonyx.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
